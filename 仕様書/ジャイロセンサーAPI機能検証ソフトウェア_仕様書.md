# ジャイロセンサーAPI機能検証ソフトウェア 仕様書

作成日: 2026年5月26日  
対象: SPIKE本体内蔵IMUを用いたジャイロセンサーAPI機能検証ソフトウェア

## 1. 目的

本ソフトウェアは、SPIKE本体に内蔵されているIMUのAPIを利用し、X軸、Y軸、Z軸の角速度、加速度、および温度を取得できることを確認するための検証用ソフトウェアである。

主な目的は、APIの学習と活用方法の理解であり、センサー精度そのものの厳密な評価は対象外とする。温度については、温度変化がどの程度発生し、ジャイロセンサーの計測値にどの程度影響するかを学習するために取得対象へ追加する。

## 2. 検証対象


| 項目   | 内容                               |
| ---- | -------------------------------- |
| 検証対象 | IMU APIの挙動                       |
| 取得対象 | X/Y/Z軸の角速度、X/Y/Z軸の加速度、IMU温度      |
| 角度算出 | 行わない                             |
| UI   | 作成しない                            |
| 合否判定 | 行わない                             |
| 保存機能 | ソフトウェア内では保存しない。標準出力をリダイレクトして保存する |


## 3. 利用者

本ソフトウェアの主な利用者は、ETロボコン競技プログラム開発者とする。

## 4. 実行環境


| 項目   | 内容                          |
| ---- | --------------------------- |
| 対象機器 | SPIKE本体                     |
| センサー | SPIKE本体内蔵IMU                |
| 接続   | Raspberry PiとSPIKE本体をUSB接続  |
| 想定環境 | 机上での手動確認、および競技用ロボット搭載状態での確認 |
| 出力先  | 標準出力                        |
| 保存方法 | 標準出力をリダイレクトしてCSVファイルとして保存   |


## 5. 使用API

以下のAPIを使用して、角速度、加速度、温度を取得する。


| API                              | 用途            |
| -------------------------------- | ------------- |
| `hub_imu_init()`                 | IMUの初期化       |
| `hub_imu_get_angular_velocity()` | X/Y/Z軸の角速度を取得 |
| `hub_imu_get_acceleration()`     | X/Y/Z軸の加速度を取得 |
| `hub_imu_get_temperature()`      | IMU温度を取得      |


## 6. 取得データ


| データ | 軸   | 意味        | 単位     |
| --- | --- | --------- | ------ |
| 角速度 | X軸  | ロール方向の角速度 | °/s    |
| 角速度 | Y軸  | ピッチ方向の角速度 | °/s    |
| 角速度 | Z軸  | ヨー方向の角速度  | °/s    |
| 加速度 | X軸  | X軸方向の加速度  | mm/s^2 |
| 加速度 | Y軸  | Y軸方向の加速度  | mm/s^2 |
| 加速度 | Z軸  | Z軸方向の加速度  | mm/s^2 |
| 温度  | なし  | IMU温度     | ℃      |


## 7. CSV出力仕様

計測結果はCSV形式で標準出力に表示する。保存が必要な場合は、実行時に標準出力をリダイレクトしてファイルに保存する。

### 7.1 ヘッダー

```csv
datetime,gyro_x_dps,gyro_y_dps,gyro_z_dps,accel_x_mms2,accel_y_mms2,accel_z_mms2,temperature_c
```

### 7.2 出力項目


| 列   | 項目              | 内容             |
| --- | --------------- | -------------- |
| 1   | `datetime`      | 計測日時           |
| 2   | `gyro_x_dps`    | X軸の角速度[°/s]    |
| 3   | `gyro_y_dps`    | Y軸の角速度[°/s]    |
| 4   | `gyro_z_dps`    | Z軸の角速度[°/s]    |
| 5   | `accel_x_mms2`  | X軸の加速度[mm/s^2] |
| 6   | `accel_y_mms2`  | Y軸の加速度[mm/s^2] |
| 7   | `accel_z_mms2`  | Z軸の加速度[mm/s^2] |
| 8   | `temperature_c` | IMU温度[℃]       |


### 7.3 出力例

```csv

```

## 8. 動作仕様

### 8.1 基本フロー

1. プログラムを起動する。
2. IMUを初期化する。
3. フォースセンサーが押下され、その後離されるまで開始待機する。
4. フォースセンサーが離されたタイミングでキャリブレーションを開始する。
5. キャリブレーション中はSPIKE本体を静止させる。
6. キャリブレーション完了後、計測を開始する。
7. 100ms周期で角速度、加速度、温度を取得する。
8. 取得した値をCSV形式で標準出力に表示する。
9. 計測中にフォースセンサーが再度押下され、その後離されたタイミングで計測を終了する。
10. プログラムを終了する。

### 8.2 計測開始

計測開始操作は、フォースセンサーを押下し、その後離す操作とする。

フォースセンサーが離されたタイミングでキャリブレーションを実施し、キャリブレーション完了後に計測を開始する。押下した瞬間ではなく、フォースセンサーが離されたタイミングを開始トリガーとする。

### 8.3 計測終了

計測中にフォースセンサーを再度押下し、その後離されたタイミングで計測を終了する。

押下した瞬間ではなく、フォースセンサーが離されたタイミングを終了トリガーとする。取りこぼしを避けるため、停止割り込み処理で停止要求フラグを立て、計測ループ側で停止要求フラグを確認して終了する。

### 8.4 更新間隔

計測値の更新間隔は100msとする。

### 8.5 キャリブレーション

キャリブレーションは、計測開始操作としてフォースセンサーが押下され、その後離されたタイミングで実施する。

キャリブレーション中はSPIKE本体を静止させる。専用のキャリブレーションAPIを前提とせず、静止状態の基準値を取得し、以降の計測値のゼロ点補正用基準として保持する。キャリブレーション完了後、CSVヘッダーを出力して計測を開始する。

計測中の再キャリブレーション機能は設けない。センターボタンによるキャリブレーションリセットも行わない。

### 8.6 異常値の扱い

明らかに異常な値が取得された場合でも、値を除外せずCSVに出力する。異常値の発生頻度を確認できるようにするためである。

### 8.7 異常時の扱い

異常が発生した場合は、エラー内容を標準出力または標準エラー出力へ通知し、安全に終了する。初期化失敗およびキャリブレーション失敗の場合は計測を開始しない。計測中のCSV出力失敗の場合は異常終了要求を立て、停止監視処理も終了できるようにして安全終了処理へ進む。


| 異常            | 扱い                    |
| ------------- | --------------------- |
| IMU初期化失敗      | 計測を開始せず終了する           |
| フォースセンサー初期化失敗 | 計測を開始せず終了する           |
| キャリブレーション失敗   | 計測を開始せず終了する           |
| CSV出力失敗       | エラーを通知し、可能な範囲で安全に終了する |


計測中に100ms周期を維持できない場合でも、異常終了はせず、取得できたデータをCSV形式で出力し続ける。

## 9. 検証観点

本ソフトウェアでは、次の観点で検証を行う。


| 観点       | 内容                                |
| -------- | --------------------------------- |
| API取得確認  | 角速度、加速度、温度がAPIから取得できること           |
| CSV出力確認  | 取得値がCSV形式で表示されること                 |
| 静止状態確認   | 静止時に角速度が0付近になること                  |
| 軸方向確認    | SPIKE本体を回転・移動させたときに対応する軸の値が変化すること |
| 温度変化確認   | 計測中の温度変化を確認できること                  |
| ドリフト確認   | 静止状態で時間経過により値がずれる傾向を確認すること        |
| 温度影響確認   | 温度変化と角速度・加速度の値の変化傾向を比較できること       |
| ロボット搭載確認 | 競技用ロボット搭載状態でも値が取得できること            |
| 長時間動作確認  | 競技中に常時計測できる程度の連続動作ができること          |


## 10. 非機能要件


| 項目  | 内容                        |
| --- | ------------------------- |
| 周期性 | 100ms周期で計測値を出力する          |
| 可読性 | CSVとして読み取りやすい列名を使用する      |
| 保存性 | 標準出力のリダイレクトによりファイル保存できる   |
| 継続性 | 少なくとも1分間の連続計測ができる         |
| 拡張性 | 必要に応じて競技中の常時計測に流用できる構成にする |


## 11. 対象外

以下は本ソフトウェアの対象外とする。

- 角速度を積分した角度の算出
- GUIまたは専用UIの作成
- ソフトウェア内でのCSVファイル保存処理
- センサー精度の厳密な評価
- 合格・不合格の自動判定
- 異常値の除外処理
- センターボタンによる計測開始・終了
- 計測中の再キャリブレーション
- センターボタンによるキャリブレーションリセット
- 温度による補正処理

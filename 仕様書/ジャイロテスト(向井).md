# テスト項目（ジャイロセンサー検証ソフトウェア）

## 1. システム検証テスト

| No | テスト項目 | 確認内容 | 期待結果 |
| :--- | :--- | :--- | :--- |
| SY-001 | システム起動 | システム起動後にセンサー類が正常に初期化されるか | 正常に待機状態へ遷移する |
| SY-002 | 計測開始操作 | 設定された開始操作（例：フォースセンサーの押下など）時の動作確認 | 意図した通りに計測を開始する |
| SY-003 | 計測終了操作 | 計測中、設定された終了操作時の動作確認 | 意図した通りに計測を終了し、待機状態に戻る |
| SY-004 | 周期動作 | 指定されたサンプリング周期（例：10ms〜1000ms）で取得・出力されるか | 周期内で安定して動作し、遅延なく出力される |
| SY-005 | CLI出力 | コンソールへの表示内容確認 | 計測値が指定形式（時間情報＋IMU取得値）のCSV形式で出力される |

## 3. ジャイロセンサー特有・動作検証テスト

| No | テスト項目 | 確認内容 | 期待結果 |
| :--- | :--- | :--- | :--- |
| GY-001 | キャリブレーション | 計測開始時（または起動時）のゼロ点調整動作確認 | 静止状態で初期値が補正・リセットされること |
| GY-002 | 静止状態ゼロ点確認 | 静止状態で計測を行った際の出力値確認 | 大きな変動が発生せず、安定した値を出力すること |
| GY-003 | 手動動作確認 | 手に持って傾けた（ロール/ピッチ/ヨー）際の出力値確認 | 傾けた方向の各軸の角速度・加速度が変化して出力されること |
| GY-004 | ドリフト・温度影響確認 | 長時間連続計測、または環境温度変化時の出力値確認 | 異常停止せず、時間経過や温度変化による値のズレ（ドリフト）がそのまま出力されること |
| GY-005 | 再現性確認 | 同一条件（同じ姿勢・動作）で複数回計測を行った際の出力値確認 | 複数回計測しても、同等条件であれば同等の数値傾向を出力すること |
| GY-006 | 実機搭載動作 | 実機ロボット搭載状態（走行・旋回時）での計測確認 | ロボットの動きや振動に合わせた数値が出力され、システムが停止しないこと |
